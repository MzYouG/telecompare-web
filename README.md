# TeleCompare Web — Price Comparator Terminal
### Apple Monochrome Liquid Glass Design

**TeleCompare Web** is a luxury, responsive price comparison interface aggregating live product catalogs, subscription rates, and deals across digital stores and Telegram seller bots.

---

## Features

- **Apple Monochrome Liquid Glass Aesthetic**: Frosted glass panels, ambient fluid canvas, precision financial typography (Inter & JetBrains Mono).
- **Dynamic Fuzzy Hierarchy Tree**: Real-time clustering of deals by service (ChatGPT, Netflix, Midjourney, Canva, CapCut, etc.).
- **Payment Filtering & Instant Search**: Filter by USDT, Visa, PayPal, BaridiMob, CCP, or Paysera.
- **Cheapest Bot Highlights**: Instant visual badges indicating the best price provider.
- **Mobile Responsive**: Native feel for iOS Safari and Android Chrome with adaptive bottom sheets.
- **Private Access Passcode Protection**: Protected with WebLACASA security gatekeeper.

---

## Deployment (GitHub Pages)

This repository is ready for instant, zero-configuration deployment on **GitHub Pages**:
1. Go to **Settings** → **Pages**.
2. Under **Build and deployment**, select **Deploy from a branch** → Branch: `main` → Folder: `/ (root)`.
3. Save and access the web terminal worldwide!

---

## Data Synchronization

The catalog (`data/products.json`) is securely synchronized via automated API pipelines from a private backend node. No backend source code or private bot credentials are exposed.
